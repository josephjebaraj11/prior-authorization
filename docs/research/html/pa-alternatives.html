Alternatives to Prior Authorization

Visual companion to pa-alternatives.md — does anything actually eliminate PA, or does everything just narrow or speed it up?

Bottom line: only one mechanism — value-based, risk-sharing contracts — changes the underlying reason PA exists. Everything else narrows or speeds up the same process.
